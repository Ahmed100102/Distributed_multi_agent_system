# LangGraph Observibot V2

The `langgraph_observibot2.py` script is an enhanced version of the original Observibot. It introduces more robust metrics collection, improved thread safety, and better application lifecycle management.

## Overview

This version of Observibot builds upon the conversational AI capabilities of the original, providing a more resilient and observable agent for interacting with the Observix platform's data in Elasticsearch.

## Key Enhancements

### 1. Advanced Metrics Collection

This version introduces a more comprehensive metrics collection system. The `global_metrics` dictionary now tracks:

-   `total_queries_processed`
-   `total_errors`
-   `total_input_tokens` and `total_output_tokens`
-   `node_counts`: The number of times each node in the graph is executed.
-   `node_durations`: The total time spent in each node.
-   `node_errors`: The number of errors that occur in each node.

These metrics are saved to `observibot_metrics.json` and provide a much deeper insight into the agent's performance and potential bottlenecks.

### 2. Thread Safety

To ensure that the `global_metrics` dictionary is updated safely in a concurrent environment, a `threading.Lock` is used. This prevents race conditions when multiple requests are processed at the same time.

### 3. Lifespan Management

The FastAPI application now uses a `lifespan` context manager. This allows for graceful startup and shutdown procedures. On shutdown, it ensures that the Elasticsearch connection is closed properly and the final metrics are saved.

### 4. Health Endpoint

The `/health` endpoint has been significantly improved to provide a more detailed overview of the agent's status, including:

-   The status of the Elasticsearch and LLM connections.
-   Detailed metrics on query processing, error rates, and token usage.
-   Statistics on thread usage.

## Architecture, State Management, and Workflow

The core architecture, state management (`ObservibotState`), and workflow remain the same as the original Observibot. It still uses FastAPI, LangGraph, Elasticsearch, and the `LLMInterface` to process user queries.

## Subgraphs and Tools

The subgraphs and tools are also identical to the original version, providing the same capabilities for handling different types of queries.

## API Endpoints

The `/chat` and `/trace` endpoints function in the same way as the original version, but they now provide more detailed metrics in their responses.

## Metrics

The Observibot V2 agent generates a rich set of metrics that are saved to the `observibot_metrics.json` file and exposed through the `/health` endpoint.

### Global Metrics

-   **`total_queries_processed`:** The total number of queries processed by the agent.
-   **`total_errors`:** The total number of errors encountered.
-   **`total_input_tokens`:** The total number of input tokens used by the LLM.
-   **`total_output_tokens`:** The total number of output tokens generated by the LLM.
-   **`runs`:** A list of all the runs, with detailed information for each.
-   **`start_time`:** The timestamp when the agent was started.
-   **`node_counts`:** A dictionary containing the number of times each node in the LangGraph workflow has been executed.
-   **`node_durations`:** A dictionary containing the total duration of each node in the LangGraph workflow.
-   **`node_errors`:** A dictionary containing the number of errors that have occurred in each node.

### Health Endpoint Metrics

The `/health` endpoint provides a snapshot of the agent's health and performance, including:

-   **`status`:** The overall health status of the agent (`healthy` or `unhealthy`).
-   **`elasticsearch`:** The status of the connection to Elasticsearch.
-   **`llm`:** The status of the connection to the LLM.
-   **`threading`:** Information about the active threads.
-   **`metrics`:** A summary of the global metrics, including error rate, average token usage, and node-level statistics.

## Configuration

The configuration remains the same, relying on environment variables to set up the Elasticsearch and LLM connections.
